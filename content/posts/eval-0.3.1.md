Eval 0.3.1 is released. [Eval](https://github.com/eed3si9n/eval) evaluates Scala 3 code. See <https://eed3si9n.com/eval/> for details.

Eval 0.3.1 introduces a workaround for the Scala 3.x VirtualFile issue on Windows [#19](https://github.com/eed3si9n/eval/pull/19).
