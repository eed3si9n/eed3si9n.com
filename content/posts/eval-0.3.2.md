Eval 0.3.2 is released. [Eval](https://github.com/eed3si9n/eval) evaluates Scala 3 code. See <https://eed3si9n.com/eval/> for details.

Eval 0.3.2 adds Scala 3.8.1 support:

* Register source name by [@som-snytt](https://github.com/som-snytt) in [#22](https://github.com/eed3si9n/eval/pull/22)
* Align the initial runId with the one used in the compiler for Scala 3.8.1 by [@jchyb](https://github.com/jchyb) in [#26](https://github.com/eed3si9n/eval/pull/26)
